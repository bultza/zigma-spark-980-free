# English translation of CN112034330A

Prepared on 2026-11-22. This is an unofficial English translation of the
Chinese patent publication, not an AM380 datasheet or a certified translation.

The PDF preserves the original 14-page organization, 12 claims, description
paragraphs [0001]–[0039], and three figures. Diagram labels are translated;
original diagram geometry, publication identifiers and page numbering are
retained. Font sizes and line wrapping were adjusted to fit the English text.
The Chinese source PDF remains unchanged.

## Source details retained without silent corrections

- The encryption-test description (step 16) compares encrypted output with
  decrypted data. This wording is retained despite its apparent inconsistency.
- ADC-test step 6 uses an all-voltages-outside-limits failure condition.
- The AM330 CHIPID example is written `0000_00003` in the source.
- The source spelling `FIAL` on description page 8/8 is retained.
- The source's DAC/ADC test-module assignments are retained.
